## aholo lux3d image-to-3d

Generate a 3D model from one image or multiple views.

Operation: `createImgTo3dTask`; SDK resource: `imgTo3d`.

| Option | Meaning |
| --- | --- |
| `--image <file>` | Upload a local reference image |
| `--image-url <url>` | Public HTTP(S) image URL |
| `--images <files...>` | Ordered local multi-view images |
| `--image-urls <urls...>` | Ordered public multi-view URLs |
| `--model-version <version>` | Official generation version |
| `--face-count <number>` | Target mesh faces, 10000–300000 |
| `--formats <formats>` | Comma-separated requested formats |
| `--pbr <boolean>` | Generate PBR mesh materials |
| `--predict-size <boolean>` | Predict physical dimensions |
| `--request <file>` | Official JSON body from a file, or - for stdin |
| `--request-id <id>` | Stable local submission identifier; reuse after interruption |
| `--wait` | Wait for the created or recovered task |
| `--download` | Wait and save all task outputs |
| `--max-wait <seconds>` | Total wait budget (default 600 seconds) |
| `--overwrite` | Explicitly replace conflicting download files |

Defaults: `{"version":"G1-Turbo","faceCount":50000,"outputFormat":["glb"],"enablePbr":true,"aiPredictSize":true}`.

- Exactly one of img or imgs is required. imgs preserves 1–32 input views in order.
- The CLI always sends an explicit version. G1 returns ZIP and GLB regardless of the requested mesh formats; requesting PLY adds PLY.
- G1-Turbo defaults here to GLB; an explicitly empty outputFormat requests the official ZIP default.
- faceCount does not affect PLY. enablePbr is effective only for G1-Turbo mesh output; the official service ignores it for G1 or PLY-only requests.

Official route: `POST /lux3d/v1/generate/img-to-3d/task/create`. For region com the SDK prepends /global.

```json
{
  "type": "object",
  "properties": {
    "img": {
      "minLength": 1,
      "pattern": ".*\\S.*",
      "type": "string"
    },
    "imgs": {
      "type": "array",
      "minItems": 1,
      "maxItems": 32,
      "items": {
        "type": "string",
        "minLength": 1,
        "pattern": ".*\\S.*"
      }
    },
    "version": {
      "type": "string",
      "enum": [
        "G1",
        "G1-Turbo"
      ]
    },
    "faceCount": {
      "type": "integer",
      "minimum": 10000,
      "maximum": 300000
    },
    "outputFormat": {
      "type": "array",
      "uniqueItems": true,
      "items": {
        "type": "string",
        "enum": [
          "zip",
          "glb",
          "ply"
        ]
      }
    },
    "enablePbr": {
      "type": "boolean"
    },
    "aiPredictSize": {
      "type": "boolean"
    }
  },
  "additionalProperties": false
}
```

- version is fixed to v3.0-standard.
- aiPredictSize=true makes the official service ignore customSize. With false/omitted, customSize is the target height in millimetres.

Official route: `POST /lux3d/v1/generate/material-transfer/task/create`. For region com the SDK prepends /global.

```json

    "img",
    "meshUrl",
    "version"
  ],
  "type": "object",
  "properties": {
    "img": {
      "minLength": 1,
      "pattern": ".*\\S.*",
      "type": "string"
    },
    "meshUrl": {
      "minLength": 1,
      "pattern": ".*\\S.*",
      "type": "string"
    },
    "version": {
      "type": "string",
      "enum": [
        "v3.0-standard"
      ]
    },
    "outputFormat": {
      "type": "array",
      "uniqueItems": true,
      "items": {
        "type": "string",
        "enum": [
          "zip",
          "glb",
          "usdz",

          "fbx_zip"
        ]
      }
    },
    "aiPredictSize": {
      "type": "boolean"
```
